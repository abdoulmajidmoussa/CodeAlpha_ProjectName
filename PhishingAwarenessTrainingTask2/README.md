# 🎣 CodeAlpha — Phishing Awareness Training

> **Task 2** of the CodeAlpha Cybersecurity Internship Program  


---

## 📌 Description

A professional **PDF presentation** built with **LaTeX Beamer** covering phishing attack awareness and prevention. Designed to educate users on how to recognize, resist, and report phishing attempts through clear explanations, real-world examples, and an interactive quiz.

## ✨ Key Topics Covered

- 📧 **Email Phishing**, Spear Phishing, Whaling, Smishing, Vishing, Pharming
- 🔎 Red flags in phishing emails (urgency, fake domains, typosquatting)
- 🌐 How to verify URLs and detect fake websites
- 🧠 Social engineering tactics: urgency, authority, pretexting, emotion
- 🛡️ Technical defenses: MFA, password managers, email filtering
- 🧩 Interactive quiz with 3 questions and detailed explanations
- 🔗 Useful resources: VirusTotal, Google Safe Browsing, PhishTank, HaveIBeenPwned

## 🛠️ Requirements

To compile the `.tex` source file:

- [TeX Live](https://www.tug.org/texlive/) or [MiKTeX](https://miktex.org/)
- Required packages: `beamer`, `fontawesome5`, `tikz`, `booktabs`, `hyperref`, `enumerate`

```bash
pdflatex phishing_awareness.tex
pdflatex phishing_awareness.tex  # Run twice for TOC
```

Or simply use the pre-compiled **PDF** directly.
